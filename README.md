# Atharv Holkar | Personal Portfolio Matrix

> **Aspiring Software Developer & Computer Science Engineering Student** at Medi-Caps University, Indore. Focused on building optimized web architectures, scalable backend systems, and high-performance applications.

This repository contains the source code for my personal portfolio website, featuring a dark-themed glassmorphism aesthetic, interactive background matrix particles, a system boot loader simulation, and an interactive **Ask Me Anything (AMA)** terminal.

---

## ✨ Key Features

* **Interactive Matrix Canvas:** Dynamic background particle animation powered by HTML5 Canvas.
* **System Boot Simulation:** A terminal-style startup sequence and security node clearance loader.
* **Responsive Architecture:** Fully optimized for mobile, tablet, and desktop viewports using Tailwind CSS.
* **Interactive AMA Terminal:** Virtualized command execution interface allowing visitors to query professional metrics and system attributes dynamically.
* **Live Deployment Links:** Quick-access gateways to deployed cloud instances and production applications.

---

## 🛠️ Tech Stack & Tools

* **Markup & Styling:** HTML5, CSS3, Tailwind CSS (via CDN)
* **Scripting:** Vanilla JavaScript (ES6+)
* **Icons:** FontAwesome Pro / Free Icons
* **Fonts:** Plus Jakarta Sans & Fira Code
* **Deployment:** Netlify / GitHub Pages
